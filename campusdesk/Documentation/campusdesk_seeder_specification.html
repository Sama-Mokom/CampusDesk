1. Purpose & Scope

This document consolidates all architectural and implementation decisions made regarding the CampusDesk database seeding strategy. It defines the dependency-ordered seeding sequence, the finalized UserFactory state design, the data generation rules governing academic identity (matricule, level, faculty/department/programme consistency), and the responsibilities of DatabaseSeeder.php. Sections marked "OPEN — NOT YET DECIDED" represent areas discussed but not yet finalized, and require further design work before implementation.

3. Finalized Architectural Decisions

3.1 Stage Generation Placement

Stage generation logic will be extracted from RequestController into a dedicated StageGenerationService, invoked automatically from a RequestObserver::created() hook. This guarantees stage generation fires identically regardless of whether a Request is created via HTTP, Tinker, or a seeder — eliminating the risk of divergent logic between production code and test data.

3.2 Faculty / Department / Programme Consistency

Because student_profiles denormalizes faculty_id alongside department_id and programme_id, all three must be mutually consistent for every seeded student. Faculty is always derived from the most specific value supplied (department takes precedence over faculty), never selected independently at random.

3.3 Role / Profile Assignment Strategy

A single afterCreating() hook, registered once inside UserFactory::configure(), is the sole authority for creating StudentProfile or StaffProfile rows. State methods (staff(), student()) do not create related rows themselves — they only override role and stash parameters as transient properties on the factory instance for the single hook to read. This avoids duplicate-insert races that would occur if multiple competing afterCreating() hooks existed.

3.4 Default Behaviour

User::factory()->create() with no state defaults to role: "student" and will always generate an associated StudentProfile, reflecting the platform's real-world user distribution. This is a deliberate default, not an oversight.

4. UserFactory Specification (Finalized)

4.1 Transient Properties

transient_faculty     = null   // Faculty|null, optional override
transient_department  = null   // Department|null, optional override
transient_level       = null   // string|null, optional override ("100"–"400")
transient_admin_level = null   // string|null, staff promotion tier

4.2 State Method — staff()

METHOD staff(admin_level = null):
    self.transient_admin_level = admin_level
    RETURN self.state(FUNCTION (attributes):
        RETURN { "role": "staff" }
    )

4.3 State Method — student()

METHOD student(faculty = null, department = null, level = null):
    self.transient_faculty    = faculty
    self.transient_department = department
    self.transient_level      = level
    RETURN self.state(FUNCTION (attributes):
        RETURN { "role": "student" }
    )

4.4 configure() — Single Authoritative Hook

METHOD configure():
    RETURN self.afterCreating(FUNCTION (user_record):

        IF user_record.role == "staff":
            CREATE StaffProfile WITH {
                "user_id": user_record.id,
                "staff_id": generate_unique_staff_id(),
                "admin_level": self.transient_admin_level   // null if staff() bypassed
            }

        ELSE IF user_record.role == "student":

            // --- Phase 1: Resolve Faculty / Department / Programme ---
            IF self.transient_department IS NOT NULL:
                RESOLVED_DEPT    = self.transient_department
                RESOLVED_FACULTY = RESOLVED_DEPT.faculty
                RESOLVED_PROG    = RANDOM_RECORD_FROM(Programmes WHERE faculty_id == RESOLVED_FACULTY.id)
                IF RESOLVED_PROG IS NULL:
                    THROW RuntimeException(
                        "No Programme found for Faculty '{name}' (id: {id}). " .
                        "Seed at least one Programme for this faculty before creating student users."
                    )

            ELSE IF self.transient_faculty IS NOT NULL:
                RESOLVED_FACULTY = self.transient_faculty
                RESOLVED_DEPT    = RANDOM_RECORD_FROM(Departments WHERE faculty_id == RESOLVED_FACULTY.id)
                IF RESOLVED_DEPT IS NULL:
                    THROW RuntimeException("No Department found for Faculty '{name}' (id: {id}). Seed departments first.")
                RESOLVED_PROG    = RANDOM_RECORD_FROM(Programmes WHERE faculty_id == RESOLVED_FACULTY.id)
                IF RESOLVED_PROG IS NULL:
                    THROW RuntimeException("No Programme found for Faculty '{name}' (id: {id}). Seed programmes first.")

            ELSE:
                RESOLVED_FACULTY = RANDOM_RECORD_FROM(Faculties)
                IF RESOLVED_FACULTY IS NULL:
                    THROW RuntimeException("No Faculties found. Run FacultySeeder before creating student users.")
                RESOLVED_DEPT = RANDOM_RECORD_FROM(Departments WHERE faculty_id == RESOLVED_FACULTY.id)
                IF RESOLVED_DEPT IS NULL:
                    THROW RuntimeException("No Department found for randomly selected Faculty '{name}' (id: {id}).")
                RESOLVED_PROG = RANDOM_RECORD_FROM(Programmes WHERE faculty_id == RESOLVED_FACULTY.id)
                IF RESOLVED_PROG IS NULL:
                    THROW RuntimeException("No Programme found for randomly selected Faculty '{name}' (id: {id}).")

            // --- Phase 1B: Resolve Level ---
            RESOLVED_LEVEL = self.transient_level ?? RANDOM_ELEMENT(["100","200","300","400"])

            // --- Phase 2: Generate Coherent Matricule ---
            FACULTY_CODE   = UPPERCASE(RESOLVED_FACULTY.code)
            SECTION_LETTER = "A"                                  // Hardcoded — registrar-owned rule, out of scope
            BASE_SYSTEM_YEAR = 2026
            LEVEL_NUMERIC    = CONVERT_TO_INT(RESOLVED_LEVEL)
            YEARS_SPENT      = (LEVEL_NUMERIC / 100) - 1
            COMPUTED_ENROLLMENT_YEAR = BASE_SYSTEM_YEAR - YEARS_SPENT
            DERIVED_YEAR_STR = SUBSTRING(CONVERT_TO_STR(COMPUTED_ENROLLMENT_YEAR), -2)
            PREFIX_MATCH     = FACULTY_CODE + DERIVED_YEAR_STR + SECTION_LETTER

            LAST_MATRICULE = QUERY(StudentProfiles)
                                .WHERE("matricule", "LIKE", PREFIX_MATCH + "%")
                                .ORDER_BY("matricule", "DESC")
                                .FIRST()
            NEXT_SEQUENCE_INT = LAST_MATRICULE IS NOT NULL
                                 ? CONVERT_TO_INT(SUBSTRING(LAST_MATRICULE.matricule, -3)) + 1
                                 : 1
            GENERATED_MATRICULE = PREFIX_MATCH + PAD_LEFT(NEXT_SEQUENCE_INT, 3, "0")

            // --- Phase 3: Persist ---
            CREATE StudentProfile WITH {
                "user_id":        user_record.id,
                "faculty_id":     RESOLVED_FACULTY.id,
                "department_id":  RESOLVED_DEPT.id,
                "programme_id":   RESOLVED_PROG.id,
                "level":          RESOLVED_LEVEL,
                "matricule":      GENERATED_MATRICULE
            }
    )
